# BHARAT 3D — Interactive Geographic Intelligence Platform

> **Tagline:** Explore India's Geography. Understand Its People. Discover Its Landscape.  
> **Application Type:** Interactive 3D GIS + Geographic Data Visualization + Educational Intelligence Platform

---

## 🌟 Overview & Architecture

**Bharat 3D** is a premium, cinematic 3D geographic intelligence platform for India. It combines 3D terrain elevation, authentic administrative boundaries, topological river networks with animated flow vectors, pedological soil classifications, and official socio-demographic statistics (Census of India Primary Census Abstract & C-01 Religion tables).

### Core Principle: Zero AI Assumption of Geographic Facts
In strict accordance with the master specification, **no geographical, demographic, religious, or geological fact is assumed or generated by AI**. Every data point displayed has an authentic, traceable provenance from sovereign Government of India portals or audited global scientific institutions.

## 🚀 How to Run Bharat 3D

### Method 1: One-Click Launch (Windows)
Double-click `start-bharat3d.bat` in the project root. It opens the browser and starts the dev server.

### Method 2: Manual Terminal Execution
```powershell
cd bharat3d-app
pnpm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Method 3: Production Build & High-Performance Preview
```powershell
cd bharat3d-app
pnpm run build
pnpm run preview
```

## 🗺️ Key Features Implemented

1. **Hardware-Accelerated 3D Terrain & Relief:**
   - Full 3D pitch ($0^\circ$ to $85^\circ$) and bearing rotation using AWS / NASA Terrarium RGB DEM elevation tiles.
   - Dynamic terrain relief exaggeration slider ($0.5\times$ to $3.0\times$).
   - Instant 2D / 3D projection toggle with smooth camera transitions.

2. **Cartographic Basemap Styles:**
   - **Dark Matter (Cyber)**: High-contrast dark raster tiles (`@2x` Retina resolution) with cyan glow boundary accents.
   - **Topographic Carto**: Traditional full topographic cartography with roads and physical features.
   - **Positron Minimal**: Crisp light presentation style.

3. **Cinematic Camera Perspectives:**
   - Quick one-click viewpoints for major geographic regions:
     - *Pan-India National Overview*
     - *Himalayan Ridge & Karakoram (3D)*
     - *Indo-Gangetic Alluvial Basin*
     - *Deccan Volcanic Plateau*
     - *Western Ghats Escarpment*
     - *Northeast & Brahmaputra Valley*

4. **Administrative Boundary Exploration:**
   - All 36 Indian States and Union Territories (ADM1) with official capitals, populations, density, and areas.
   - 735 District administrative boundaries (ADM2) enriched with Census 2011 microdata.
   - State Name Typography Grid directly rendered on map with zoom-responsive scaling.
   - Dynamic boundary highlighting and camera fly-to on selection.

5. **Animated River Systems & Tributaries:**
   - Dual-layer glowing cyan lines with smooth throttled particle animations (optimized 120ms tick).
   - Major basins: Ganga, Brahmaputra, Indus, Godavari, Krishna, Kaveri, Mahanadi, Narmada, Tapi, Sabarmati.
   - Comprehensive hydrological dossiers: length, origin elevation, outflow confluences, riparian states, major dams, and key cities.

6. **Soil Geography Layer (ICAR):**
   - 8-fold ICAR-NBSS&LUP scientific soil classification (Alluvial, Black/Regur, Red & Yellow, Laterite, Arid/Desert, Mountain & Forest).
   - Agricultural suitability profiles, geological genesis, and regional extent.

7. **Demographic Intelligence (Census of India 2011 & 2001):**
   - Fully joined district-level choropleths:
     - **Population Density** ($persons / km^2$) with multi-stop plasma color ramp.
     - **Total Population** volume scale.
     - **Literacy Rate** percentage scale.
     - **Sex Ratio** (Females per 1,000 Males).
     - **Rural vs Urban** demographic splits.

8. **Religious Demographics Explorer (Census 2011 Table C-01):**
   - Dedicated district-level choropleths for 6 major religious communities (Hindu, Muslim, Christian, Sikh, Buddhist, Jain).

9. **Cinematic Splash Screen & Search Autocomplete:**
   - Progressive loading screen calibrating administrative, hydrographic, and elevation datasets.
   - Real-time search with dropdown suggestions matching states, rivers, mountains, and cities.

10. **In-App Source Registry & Provenance Modal:**
    - Transparent auditing of all publishing institutions, coordinate reference systems, reference years, and licenses.
